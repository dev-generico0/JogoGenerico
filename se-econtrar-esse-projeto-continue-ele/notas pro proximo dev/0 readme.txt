oi, dev_0 por aqui de novo 👋

antes de começar qualquer coisa, confirma se você está usando a versão 
mais atualizada do projeto:

https://github.com/otavioFmiranda/Oi_dev

para contribuir, faz um fork do repositório no GitHub e depois 
clona o seu fork:

-----------------
git clone https://github.com/SEU_USUARIO/Oi_dev.git
cd Oi_dev
-----------------

agora conecta o repositório original como upstream para conseguir 
atualizar seu fork futuramente:

-----------------
git remote add upstream https://github.com/otavioFmiranda/Oi_dev.git
-----------------

antes de começar qualquer alteração, atualiza tudo:

-----------------
git fetch upstream
git pull upstream main
-----------------

cria uma branch para trabalhar:

-----------------
git checkout -b "nome-da-branch"
-----------------

faz suas alterações normalmente e depois envia:

-----------------
git add .
git commit -m "descrição da alteração"
git push origin nome-da-branch
-----------------

quando terminar, abre um Pull Request do seu fork para o repositório original.

evita trabalhar direto na main, sempre atualiza o fork antes de começar 
e nunca commita senha, token ou qualquer credencial no projeto

ou usa IA para resolver esse b.o todo para voce kkkkkkkkkkkk
